# Repo Reviewer Agent

An AI-powered repository reviewer built from scratch.

This project follows the journey from a simple ReAct loop to a production-ready AI agent with:

- Tool Calling
- Memory
- Planning
- Reflection
- MCP
- LangChain
- LangGraph
